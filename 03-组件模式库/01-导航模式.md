# 导航模式

> 常见导航设计模式汇总

---

## 一、移动端导航模式

### 1. 底部Tab导航（Bottom Tab Bar）

**适用场景**：3-5个顶级模块，需要频繁切换

```
┌─────────────────────────────────┐
│                                 │
│           内容区域               │
│                                 │
├─────────────────────────────────┤
│  🏠      🔍      ➕      💬      👤  │
│ 首页    发现    发布    消息    我的 │
└─────────────────────────────────┘
```

**规范**：
- Tab数量：3-5个（最多5个）
- 图标大小：24×24px
- 文字大小：10px
- 高度：49px(iOS) / 56px(Android)
- 选中态：主色图标+文字
- 未选中态：灰色图标+文字

**优点**：
- 始终可见，切换方便
- 符合单手操作习惯

**缺点**：
- 数量有限（最多5个）
- 占用屏幕空间

---

### 2. 顶部Tab导航（Top Tab Bar）

**适用场景**：同一模块下的分类切换

```
┌─────────────────────────────────┐
│  标题                           │
├─────────────────────────────────┤
│  全部  |  分类A  |  分类B  |  +  │
├─────────────────────────────────┤
│                                 │
│           内容区域               │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- Tab数量：2-5个（可滑动更多）
- 高度：40-48px
- 选中态：主色文字+下划线
- 未选中态：灰色文字

**变体**：
- 分段控制器（Segmented Control）：iOS风格
- 胶囊标签：圆角标签样式
- 滑动标签：可左右滑动查看更多

---

### 3. 侧边抽屉导航（Drawer/汉堡菜单）

**适用场景**：模块较多，不常切换

```
┌─────────────────────────────────┐
│≡  标题                    [操作] │
├─────────────────────────────────┤
│                                 │
│           内容区域               │
│                                 │
└─────────────────────────────────┘

点击 ≡ 后展开：
┌────────┬────────────────────────┐
│ 头像    │                        │
│ 用户名  │                        │
├────────┤      内容区域（遮罩）    │
│ 首页    │                        │
│ 分类A   │                        │
│ 分类B   │                        │
│ 设置    │                        │
└────────┴────────────────────────┘
```

**规范**：
- 抽屉宽度：屏幕宽度的70-85%
- 背景遮罩：rgba(0,0,0,0.5)
- 滑出动画：300ms

**优点**：
- 可容纳更多导航项
- 不占用主屏幕空间

**缺点**：
- 导航项不可见，需要点击展开
- 增加操作步骤

---

### 4. 宫格导航（Grid Navigation）

**适用场景**：功能入口多，需要一目了然

```
┌─────────────────────────────────┐
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐│
│  │ 图标 │ │ 图标 │ │ 图标 │ │ 图标 ││
│  │ 功能A│ │ 功能B│ │ 功能C│ │ 功能D││
│  └─────┘ └─────┘ └─────┘ └─────┘│
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐│
│  │ 图标 │ │ 图标 │ │ 图标 │ │ 图标 ││
│  │ 功能E│ │ 功能F│ │ 功能G│ │ 功能H││
│  └─────┘ └─────┘ └─────┘ └─────┘│
└─────────────────────────────────┘
```

**规范**：
- 每行数量：4-5个
- 图标大小：40-48px
- 文字大小：12px
- 间距：16-24px

**变体**：
- 可滑动宫格：更多功能可左右滑动
- 可展开宫格：点击展开更多选项

---

### 5. 列表导航（List Navigation）

**适用场景**：设置页、个人中心

```
┌─────────────────────────────────┐
│  个人中心                        │
├─────────────────────────────────┤
│  [头像] 用户名              >   │
├─────────────────────────────────┤
│  📋 我的订单                >   │
│  ⭐ 我的收藏                >   │
│  🎫 优惠券                  >   │
├─────────────────────────────────┤
│  ⚙️ 设置                    >   │
│  ❓ 帮助与反馈              >   │
└─────────────────────────────────┘
```

**规范**：
- 行高：48-56px
- 图标大小：20-24px
- 右边距：16px
- 分割线：1px #E5E7EB

## 二、PC端导航模式

### 1. 侧边导航（Side Navigation）

**适用场景**：B端后台系统，模块多

```
深色主题：
┌────────┬────────────────────────┐
│ Logo   │                        │
├────────┤                        │
│ 🏠 首页 │      内容区域          │
│ 📊 数据 │                        │
│ 👥 用户 │                        │
│ 📦 订单 │                        │
├────────┤                        │
│ ⚙️ 设置 │                        │
└────────┴────────────────────────┘

浅色主题：
┌────────┬────────────────────────┐
│ Logo   │                        │
├────────┤                        │
│ 🏠 首页 │      内容区域          │
│ 📊 数据 │                        │
│  ├ 子项1│                        │
│  └ 子项2│                        │
│ 👥 用户 │                        │
└────────┴────────────────────────┘
```

**规范**：
- 宽度：200-256px
- 背景：深色(#001529)或浅色(#FFFFFF)
- 菜单项高度：40px
- 选中态：主色背景或左边框
- 可展开子菜单

**变体**：
- 可收起侧边栏：只显示图标
- 悬浮侧边栏：鼠标悬停展开

---

### 2. 顶部导航（Top Navigation）

**适用场景**：模块少，内容型网站

```
┌─────────────────────────────────────────┐
│  Logo    首页  产品  解决方案  价格   [登录] [注册] │
└─────────────────────────────────────────┘

带下拉菜单：
┌─────────────────────────────────────────┐
│  Logo    首页  产品 ▼  关于我们        [搜索] │
│              ├─ 产品A                   │
│              ├─ 产品B                   │
│              └─ 产品C                   │
└─────────────────────────────────────────┘
```

**规范**：
- 高度：56-64px
- Logo宽度：120-200px
- 导航项间距：24-32px
- 背景：白色或透明

---

### 3. 混合导航（Mixed Navigation）

**适用场景**：复杂后台系统，模块多且有层级

```
┌─────────────────────────────────────────────────────┐
│  Logo          顶部导航（一级）              [用户]   │
├──────────┬──────────────────────────────────────────┤
│  侧边栏   │  二级导航（Tab）                          │
│ （一级）  │  Tab1 | Tab2 | Tab3                      │
├──────────┼──────────────────────────────────────────┤
│          │                                          │
│  功能菜单  │              内容区域                    │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

---

### 4. 面包屑导航（Breadcrumb）

**适用场景**：层级深的页面，需要知道位置

```
首页 / 产品中心 / 电子产品 / 手机 / iPhone 15

或：
首页 > 产品中心 > 电子产品 > 手机 > iPhone 15
```

**规范**：
- 分隔符：/ 或 >
- 字号：14px
- 颜色：前面灰色，当前黑色
- 可点击：除当前页外都可点击返回
- 位置：内容区顶部

## 三、导航选择决策

### 移动端导航选择

| 场景 | 推荐导航 | 原因 |
|------|----------|------|
| 3-5个核心模块 | 底部Tab | 切换方便，始终可见 |
| 模块下的分类 | 顶部Tab | 同层级切换 |
| 模块多且不常切换 | 侧边抽屉 | 节省空间 |
| 功能入口多 | 宫格导航 | 一目了然 |
| 设置/个人中心 | 列表导航 | 清晰有序 |

### PC端导航选择

| 场景 | 推荐导航 | 原因 |
|------|----------|------|
| B端后台系统 | 侧边导航 | 模块多，需要稳定导航 |
| 内容型网站 | 顶部导航 | 简洁，突出内容 |
| 复杂系统 | 混合导航 | 层级清晰 |
| 深层级页面 | 面包屑 | 定位明确 |

## 四、导航设计原则

### 1. 可见性原则

- 核心导航始终可见
- 当前位置明确指示
- 可点击元素有视觉区分

### 2. 一致性原则

- 同类导航样式一致
- 选中态样式统一
- 交互反馈一致

### 3. 简洁性原则

- 导航项不超过7个
- 使用清晰的标签
- 避免嵌套过深

### 4. 可访问性原则

- 支持键盘导航
- 有焦点指示
- 屏幕阅读器友好
