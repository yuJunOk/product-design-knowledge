# 列表模式

> 常见列表设计模式

---

## 一、基础列表

### 1. 简单列表

**适用场景**：设置页、个人中心

```
┌─────────────────────────────────┐
│  📋 我的订单                >   │
├─────────────────────────────────┤
│  ⭐ 我的收藏                >   │
├─────────────────────────────────┤
│  🎫 优惠券                  >   │
├─────────────────────────────────┤
│  ⚙️ 设置                    >   │
└─────────────────────────────────┘
```

**规范**：
- 行高：48-56px
- 图标：20-24px
- 右边箭头：表示可进入
- 分割线：1px

---

### 2. 图文列表

**适用场景**：内容列表、商品列表

```
┌─────────────────────────────────┐
│  ┌─────┐                        │
│  │     │  标题文字               │
│  │ 图  │  描述文字               │
│  │     │  辅助信息          标签 │
│  └─────┘                        │
├─────────────────────────────────┤
│  ┌─────┐                        │
│  │     │  标题文字               │
│  │ 图  │  描述文字               │
│  │     │  辅助信息          标签 │
│  └─────┘                        │
└─────────────────────────────────┘
```

**规范**：
- 图片：80-120px，固定宽度
- 标题：16px，单行或双行
- 描述：14px，灰色
- 辅助信息：12px

---

### 3. 卡片列表

**适用场景**：信息流、商品流

```
┌─────────────────────────────────┐
│  ┌─────────────────────────┐   │
│  │        封面图            │   │
│  │                         │   │
│  ├─────────────────────────┤   │
│  │  标题                   │   │
│  │  描述文字               │   │
│  │  👤 作者  ·  ⏱ 2小时前  │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │        封面图            │   │
│  │                         │   │
│  ├─────────────────────────┤   │
│  │  标题                   │   │
│  │  描述文字               │   │
│  │  👤 作者  ·  ⏱ 2小时前  │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

**规范**：
- 卡片间距：12-16px
- 卡片圆角：8-12px
- 卡片阴影：轻微阴影
- 图片比例：16:9 或 4:3

## 二、高级列表

### 4. 分组列表

**适用场景**：通讯录、分类展示

```
┌─────────────────────────────────┐
│  A                              │
├─────────────────────────────────┤
│  Alice                          │
├─────────────────────────────────┤
│  Amy                            │
├─────────────────────────────────┤
│  B                              │
├─────────────────────────────────┤
│  Bob                            │
├─────────────────────────────────┤
│  Betty                          │
└─────────────────────────────────┘
```

**规范**：
- 分组标题：14px，灰色背景
- 分组标题高度：32px
- 支持侧边快速索引

---

### 5. 可展开列表

**适用场景**：FAQ、多级分类

```
┌─────────────────────────────────┐
│  问题1                    [+]   │
├─────────────────────────────────┤
│  问题2                    [-]   │
│  答案内容...                    │
│  答案内容...                    │
├─────────────────────────────────┤
│  问题3                    [+]   │
└─────────────────────────────────┘
```

**规范**：
- 展开图标：+ / - 或 ▼ / ▶
- 展开动画：300ms
- 默认状态：可全部折叠或展开第一项

---

### 6. 可编辑列表

**适用场景**：待办事项、购物车

```
┌─────────────────────────────────┐
│  [√]  已完成事项           [删除] │
├─────────────────────────────────┤
│  [ ]  待办事项1            [删除] │
├─────────────────────────────────┤
│  [ ]  待办事项2            [删除] │
├─────────────────────────────────┤
│  + 添加新事项                    │
└─────────────────────────────────┘
```

**规范**：
- 支持左滑删除
- 支持拖拽排序
- 支持批量操作

## 三、特殊列表

### 7. 时间轴列表

**适用场景**：订单状态、动态记录

```
┌─────────────────────────────────┐
│  ● 已签收                       │
│  │ 2024-01-01 14:00            │
│  │ 您的订单已签收               │
│  │                             │
│  ○ 派送中                       │
│  │ 2024-01-01 10:00            │
│  │ 快递员正在派送               │
│  │                             │
│  ○ 运输中                       │
│  │ 2024-01-01 08:00            │
│  │ 订单已从仓库发出             │
└─────────────────────────────────┘
```

**规范**：
- 当前状态：实心圆点
- 过去状态：空心圆点或灰色
- 时间线：垂直线条

---

### 8. 瀑布流列表

**适用场景**：图片墙、Pinterest风格

```
┌─────────────────┬─────────────────┐
│  ┌───────────┐  │  ┌───────────┐  │
│  │           │  │  │           │  │
│  │   图片1   │  │  │   图片2   │  │
│  │           │  │  │           │  │
│  │           │  │  └───────────┘  │
│  ├───────────┤  │  标题2          │
│  │  标题1    │  │                 │
│  └───────────┘  │  ┌───────────┐  │
│                 │  │           │  │
│  ┌───────────┐  │  │   图片3   │  │
│  │           │  │  │           │  │
│  │   图片4   │  │  │           │  │
│  │           │  │  │           │  │
│  │           │  │  ├───────────┤  │
│  ├───────────┤  │  │  标题3    │  │
│  │  标题4    │  │  └───────────┘  │
│  └───────────┘  │                 │
└─────────────────┴─────────────────┘
```

**规范**：
- 两列或三列
- 高度自适应
- 间距：8-12px

## 四、列表交互

### 下拉刷新

- 触发：下拉一定距离
- 反馈：加载动画
- 结果：刷新列表数据

### 上拉加载

- 触发：滚动到底部
- 反馈：加载提示
- 结果：加载更多数据
- 结束：显示"没有更多"

### 左滑操作

- 触发：左滑列表项
- 操作：显示操作按钮
- 常见操作：删除、编辑、收藏

---

## 五、列表设计原则

1. **一致性**：同类列表样式一致
2. **反馈**：操作后有明确反馈
3. **性能**：大数据量时虚拟滚动
4. **空状态**：无数据时显示提示
5. **错误状态**：加载失败可重试
