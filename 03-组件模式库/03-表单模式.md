# 表单模式

> 常见表单设计模式

---

## 一、基础表单

### 1. 单行表单

**适用场景**：简单信息录入

```
┌─────────────────────────────────┐
│  用户名              [输入框   ] │
├─────────────────────────────────┤
│  手机号              [输入框   ] │
├─────────────────────────────────┤
│  邮箱                [输入框   ] │
└─────────────────────────────────┘
```

**规范**：
- 标签左对齐或顶对齐
- 输入框高度：40-48px
- 间距：16-24px

---

### 2. 分组表单

**适用场景**：信息分类较多

```
┌─────────────────────────────────┐
│  基础信息                        │
├─────────────────────────────────┤
│  姓名                [输入框   ] │
├─────────────────────────────────┤
│  手机号              [输入框   ] │
├─────────────────────────────────┤
│                                 │
│  详细信息                        │
├─────────────────────────────────┤
│  地址                [输入框   ] │
├─────────────────────────────────┤
│  邮编                [输入框   ] │
└─────────────────────────────────┘
```

**规范**：
- 分组标题：14-16px，加粗
- 分组间距：24-32px
- 组内间距：16px

---

## 二、表单元素

### 3. 文本输入

**类型**：
- 单行文本：text
- 多行文本：textarea
- 密码：password
- 数字：number
- 手机号：tel
- 邮箱：email

**规范**：
- 占位符：提示输入内容
- 字数限制：显示当前/最大字数
- 清除按钮：输入后显示

---

### 4. 选择器

**单选**：
```
┌─────────────────────────────────┐
│  性别                            │
├─────────────────────────────────┤
│  ○ 男                           │
├─────────────────────────────────┤
│  ○ 女                           │
└─────────────────────────────────┘
```

**多选**：
```
┌─────────────────────────────────┐
│  兴趣爱好                        │
├─────────────────────────────────┤
│  [√] 阅读                       │
├─────────────────────────────────┤
│  [ ] 运动                       │
├─────────────────────────────────┤
│  [√] 音乐                       │
└─────────────────────────────────┘
```

**下拉选择**：
```
┌─────────────────────────────────┐
│  城市                    [请选择▼]│
└─────────────────────────────────┘
```

---

### 5. 开关与滑块

**开关（Switch）**：
```
┌─────────────────────────────────┐
│  消息通知                   [开关]│
└─────────────────────────────────┘
```

**滑块（Slider）**：
```
┌─────────────────────────────────┐

│  低              高              │
```

## 三、高级表单

### 7. 分步表单

**适用场景**：复杂流程，需要分步完成

```
┌─────────────────────────────────┐
│  步骤1 → 步骤2 → 步骤3          │
│  [√]    [●]    [○]             │
├─────────────────────────────────┤
│                                 │
│  步骤2：填写详细信息             │
│                                 │
│  字段1               [输入框   ] │
│                                 │
│  字段2               [输入框   ] │
│                                 │
│                                 │
│     [上一步]        [下一步]     │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 步骤数：3-5步为宜
- 显示进度：当前步骤高亮
- 支持返回上一步
- 最后一步显示汇总

---

### 8. 动态表单

**适用场景**：字段数量不固定

```
┌─────────────────────────────────┐
│  教育经历                        │
├─────────────────────────────────┤
│  学校                [输入框   ] │
│  专业                [输入框   ] │
│  时间                [日期范围 ] │
│                         [删除]  │
├─────────────────────────────────┤
│  学校                [输入框   ] │
│  专业                [输入框   ] │
│  时间                [日期范围 ] │
│                         [删除]  │
├─────────────────────────────────┤
│  + 添加更多                      │
└─────────────────────────────────┘
```

## 四、表单验证

### 验证时机

| 时机 | 说明 |
|------|------|
| 失焦验证 | 输入框失去焦点时验证 |
| 实时验证 | 输入过程中实时验证 |
| 提交验证 | 点击提交时统一验证 |

### 验证提示

```
┌─────────────────────────────────┐
│  手机号              [1381234   ] │
│  ⚠️ 请输入正确的手机号           │
└─────────────────────────────────┘
```

**规范**：
- 错误提示：红色，图标+文字
- 成功提示：绿色对勾（可选）
- 提示位置：输入框下方或右侧

### 常见验证规则

| 字段 | 规则 |
|------|------|
| 手机号 | 11位数字，1开头 |
| 邮箱 | 包含@和域名 |
| 密码 | 6-20位，包含字母和数字 |
| 必填项 | 不能为空 |

---

## 五、表单设计原则

1. **减少输入**：使用选择器代替输入
2. **智能默认**：提供合理的默认值
3. **即时反馈**：验证错误即时提示
4. **分步展示**：复杂表单分步完成
5. **明确按钮**：提交按钮状态明确
