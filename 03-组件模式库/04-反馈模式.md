# 反馈模式

> 常见反馈设计模式

---

## 一、轻量反馈

### 1. Toast 提示

**适用场景**：操作结果提示，自动消失

**成功提示**：
```
┌─────────────────────────────────┐
│                                 │
│        ✅ 操作成功               │
│                                 │
└─────────────────────────────────┘
```

**失败提示**：
```
┌─────────────────────────────────┐
│                                 │
│        ❌ 操作失败，请重试        │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 位置：居中或底部
- 时长：2-3秒
- 背景：半透明黑色
- 文字：白色
- 图标：可选

---

### 2. Loading 加载

**适用场景**：等待操作完成

**全屏加载**：
```
┌─────────────────────────────────┐
│                                 │
│           Loading...            │
│                                 │
│        （旋转动画）              │
│                                 │
└─────────────────────────────────┘
```

**局部加载**：
```
┌─────────────────────────────────┐
│  内容区域                        │
│  ┌─────────────────────────┐   │
│  │                         │   │
│  │      Loading...         │   │
│  │                         │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

**按钮加载**：
```
┌─────────────────────────────────┐
│      [Loading... 提交中]        │
└─────────────────────────────────┘
```

**规范**：
- 全屏加载：页面切换时使用
- 局部加载：内容区域加载
- 按钮加载：表单提交时使用
- 可取消：长时间加载提供取消

---

## 二、对话框反馈

### 3. Alert 警告框

**适用场景**：重要信息提示，需用户确认

```
┌─────────────────────────────────┐
│  提示                      [×]  │
├─────────────────────────────────┤
│                                 │
│      确定要删除这条记录吗？       │
│                                 │
│      删除后无法恢复              │
│                                 │
├─────────────────────────────────┤
│      [取消]      [确定删除]     │
└─────────────────────────────────┘
```

**规范**：
- 标题：简洁明了
- 内容：说明后果
- 按钮：取消在左，确认在右
- 危险操作：确认按钮用红色

---

### 4. ActionSheet 动作面板

**适用场景**：多个操作选项

```
┌─────────────────────────────────┐
│                                 │
│  ┌─────────────────────────┐   │
│  │      请选择操作          │   │
│  ├─────────────────────────┤   │
│  │        拍照              │   │
│  ├─────────────────────────┤   │
│  │      从相册选择          │   │
│  ├─────────────────────────┤   │
│  │        取消              │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 从底部弹出
- 取消按钮单独一行
- 危险操作用红色
- 点击遮罩可关闭

---

## 三、状态反馈

### 5. 空状态

**适用场景**：无数据时

**简单空状态**：
```
┌─────────────────────────────────┐
│                                 │
│         [空状态图标]            │
│                                 │
│         暂无数据                │
│                                 │
└─────────────────────────────────┘
```

**引导空状态**：
```
┌─────────────────────────────────┐
│                                 │
│         [空状态插图]            │
│                                 │
│      还没有订单哦               │
│    快去选购心仪的商品吧          │
│                                 │
│      [去逛逛]                   │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 图标/插图：符合场景
- 文案：友好引导
- 操作：提供下一步引导

---

### 6. 错误状态

**适用场景**：加载失败、网络错误

**网络错误**：
```
┌─────────────────────────────────┐
│                                 │
│         [网络错误图标]          │
│                                 │
│      网络连接失败               │
│    请检查网络设置后重试          │
│                                 │
│      [重新加载]                 │
│                                 │
└─────────────────────────────────┘
```

**加载失败**：
```
┌─────────────────────────────────┐
│                                 │
│         [错误图标]              │
│                                 │
│      加载失败                   │
│    点击重新加载                  │
│                                 │
│      [重新加载]                 │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 说明原因
- 提供解决方案
- 提供重试入口

---

### 7. 成功状态

**适用场景**：操作完成

```
┌─────────────────────────────────┐
│                                 │
│         ✅                      │
│                                 │
│      支付成功！                 │
│    订单号：123456789            │
│                                 │
│   [查看订单]    [返回首页]      │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 明确成功信息
- 提供后续操作
- 重要信息突出显示

---

## 四、进度反馈

### 8. 进度条

**适用场景**：长时间操作，显示进度

**线性进度条**：
```
┌─────────────────────────────────┐
│  上传中...  50%                 │
│  █████████░░░░░░░░░░            │
│  2.5MB / 5MB                    │
└─────────────────────────────────┘
```

**圆形进度条**：
```
┌─────────────────────────────────┐
│                                 │
│            ┌─────┐              │
│           /  75%  \             │
│           \       /             │
│            └─────┘              │
│                                 │
│         正在处理中...           │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 显示百分比
- 显示预计时间（可选）
- 支持取消操作

---

### 9. 步骤条

**适用场景**：多步骤流程

```
┌─────────────────────────────────┐
│                                 │
│   [√]────[√]────[●]────[○]     │
│   提交    审核    处理    完成   │
│                                 │
│  当前状态：正在处理中            │
│  预计完成时间：2小时             │
│                                 │
└─────────────────────────────────┘
```

**规范**：
- 已完成：绿色对勾
- 进行中：高亮显示
- 未开始：灰色
- 可点击：已完成的步骤可点击返回

---

## 五、实时反馈

### 10. Badge 徽标

**适用场景**：未读消息、数量提示

```
┌─────────────────────────────────┐
│  消息  🔴9                      │
└─────────────────────────────────┘
```

**规范**：
- 红点：有新内容
- 数字：显示具体数量（超过99显示99+）
- 位置：右上角

---

### 11. 通知提醒

**适用场景**：重要消息推送

```
┌─────────────────────────────────┐
│  🔔 您有一条新消息              │
├─────────────────────────────────┤
│  消息内容摘要...                │
│  10分钟前                       │
└─────────────────────────────────┘
```

**规范**：
- 顶部或右上角弹出
- 自动消失或手动关闭
- 点击可跳转

---

## 六、反馈设计原则

1. **及时性**：操作后立即反馈
2. **明确性**：反馈信息清晰明确
3. **友好性**：避免指责用户
4. **可操作性**：提供解决方案
5. **适度性**：根据重要性选择反馈强度

---

## 反馈强度选择

| 场景 | 反馈方式 | 强度 |
|------|----------|------|
| 保存成功 | Toast | 低 |
| 表单错误 | 字段提示 | 低 |
| 删除确认 | Alert | 中 |
| 支付成功 | 结果页 | 高 |
| 系统错误 | 错误页 | 高 |
