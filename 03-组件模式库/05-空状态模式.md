# 空状态模式

> 空状态设计模式汇总

---

## 一、空状态类型

### 1. 初始空状态

**适用场景**：用户首次使用，还没有数据

```
┌─────────────────────────────────┐
│                                 │
│         [欢迎插图]              │
│                                 │
│      欢迎使用XX功能             │
│    点击下方的按钮开始创建        │
│                                 │
│      [创建第一条]               │
│                                 │
└─────────────────────────────────┘
```

**设计要点**：
- 欢迎语友好
- 说明功能价值
- 提供明确的开始按钮

---

### 2. 无数据空状态

**适用场景**：筛选/搜索后无结果

```
┌─────────────────────────────────┐
│                                 │
│         [搜索插图]              │
│                                 │
│      没有找到相关结果           │
│    换个关键词试试                │
│                                 │
│      [清除筛选]                 │
│                                 │
└─────────────────────────────────┘
```

**设计要点**：
- 说明原因
- 提供重置/清除操作
- 提供搜索建议（可选）

---

### 3. 无权限空状态

**适用场景**：用户没有查看权限

```
┌─────────────────────────────────┐
│                                 │
│         [锁图标]                │
│                                 │
│      暂无权限查看               │
│    请联系管理员申请权限          │
│                                 │
│      [联系管理员]               │
│                                 │
└─────────────────────────────────┘
```

**设计要点**：
- 说明原因（无权限/未登录）
- 提供解决方案
- 提供操作入口

---

### 4. 无网络空状态

**适用场景**：网络连接失败

```
┌─────────────────────────────────┐
│                                 │
│         [断网插图]              │
│                                 │
│      网络连接失败               │
│    请检查网络设置后重试          │
│                                 │
│      [重新加载]                 │
│                                 │
└─────────────────────────────────┘
```

**设计要点**：
- 说明网络问题
- 提供重试操作
- 缓存数据可离线查看（如有）

---

### 5. 错误空状态

**适用场景**：加载失败、系统错误

```
┌─────────────────────────────────┐
│                                 │
│         [错误插图]              │
│                                 │
│      加载失败                   │
│    服务器开小差了，请稍后重试     │
│                                 │
│      [重新加载]                 │
│                                 │
└─────────────────────────────────┘
```

**设计要点**：
- 避免技术术语
- 用友好语气
- 提供重试入口

## 二、空状态设计要素

### 视觉元素

| 元素 | 说明 | 示例 |
|------|------|------|
| 插图 | 符合场景的插画 | 空盒子、搜索、断网等 |
| 图标 | 简洁的图标 | 空状态图标 |
| 颜色 | 柔和的颜色 | 灰色、浅色 |

### 文案要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 标题 | 一句话说明状态 | "暂无订单" |
| 描述 | 补充说明原因 | "您还没有下单，快去选购吧" |
| 操作 | 引导用户操作 | "去逛逛" |

### 操作按钮

| 场景 | 按钮文案 | 操作 |
|------|----------|------|
| 初始状态 | 创建/开始/添加 | 进入创建流程 |
| 搜索无结果 | 清除筛选/重置 | 清除条件 |
| 无权限 | 申请权限/登录 | 去申请/登录 |
| 网络错误 | 重新加载/刷新 | 重新请求 |

---

## 三、空状态设计原则

### 1. 不要责怪用户

❌ 错误："你没有创建任何内容"
✅ 正确："还没有内容，点击创建"

### 2. 提供明确引导

❌ 错误：只显示"暂无数据"
✅ 正确：说明原因 + 提供操作

### 3. 保持品牌调性

- 使用品牌色
- 使用品牌插画风格
- 语气符合品牌定位

### 4. 考虑情感化

- 使用有趣的插图
- 用轻松的语气
- 让用户感到舒适
