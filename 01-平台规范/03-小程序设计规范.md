# 小程序设计规范

> 微信小程序/支付宝小程序设计规范

---

## 一、设计尺寸

### 标准尺寸

| 项目 | 规格 | 说明 |
|------|------|------|
| 设计画布 | 750 × 1334px | iPhone 6/7/8 标准 |
| 设计画布(推荐) | 375 × 667px | 1倍图，更精确 |
| 状态栏高度 | 20px | 系统预留 |
| 导航栏高度 | 44px | 小程序固定 |
| 底部安全区 | 0-34px | iPhone X+ 需要适配 |
| TabBar高度 | 56px | 小程序固定 |

### 适配规则

- 使用 `rpx` 作为尺寸单位
- 1rpx = 0.5px = 1物理像素
- 设计稿 750px 宽度下，1px = 1rpx

## 二、官方组件规范

### 基础组件

#### 按钮 button

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| primary | 绿色填充(#07C160) | 主要操作 |
| default | 白色背景，灰色边框 | 次要操作 |
| warn | 红色填充(#FA5151) | 警告操作 |

**尺寸**：
- 默认：宽度自适应，高度 40px
- mini：小尺寸按钮

#### 输入框 input

| 属性 | 规范 |
|------|------|
| 高度 | 40px |
| 边框 | 1px #E5E5E5 |
| 圆角 | 4px |
| 内边距 | 8px 12px |

#### 列表 cell

| 属性 | 规范 |
|------|------|
| 高度 | 48px |
| 左边距 | 16px |
| 右边距 | 16px |
| 分割线 | 1px #E5E5E5 |

## 三、自定义组件规范

### 导航栏

```
┌─────────────────────────────────┐
│  Capsule [标题]              [···] │
└─────────────────────────────────┘
```

- 左侧胶囊按钮：系统固定，不可修改
- 标题：居中，18px
- 高度：44px

### TabBar

```
┌─────────────────────────────────┐
│  [图标]    [图标]    [图标]    [图标] │
│  首页      分类      购物车    我的  │
└─────────────────────────────────┘
```

- 数量：2-5个
- 图标：25 × 25px
- 文字：10px
- 选中态：绿色(#07C160)
- 未选中态：灰色(#999999)

## 六、页面设计规范

### 页面结构

```
┌─────────────────────────────────┐
│  状态栏（系统）                   │  20px
├─────────────────────────────────┤
│  导航栏（系统）                   │  44px
├─────────────────────────────────┤
│                                 │
│         内容区域                  │
│                                 │
├─────────────────────────────────┤
│  TabBar（可选）                  │  56px
└─────────────────────────────────┘
```

### 页面边距

- 页面边距：16px
- 卡片内边距：16px
- 列表项高度：48-56px

## 七、交互规范

### 页面跳转

| 方式 | 说明 |
|------|------|
| navigateTo | 保留当前页，可返回 |
| redirectTo | 关闭当前页，不可返回 |
| switchTab | 跳转到TabBar页 |
| reLaunch | 关闭所有页，重新打开 |

### 下拉刷新

- 默认支持下拉刷新
- 刷新动画：官方样式
- 触发距离：下拉一定距离后触发

### 上拉加载

- 列表底部加载更多
- 显示加载提示
- 无更多数据时显示提示

## 八、设计原则

### 微信官方原则

1. **友好礼貌**：避免用户过度授权，减少打扰
2. **清晰明确**：导航清晰，反馈及时
3. **便捷优雅**：减少输入，避免误操作
4. **统一稳定**：风格统一，体验一致

### 小程序特有注意事项

- 包大小限制：2MB（可分包扩展到 20MB）
- 页面层级限制：最多10层
- 避免复杂动画，保证流畅性
- 考虑弱网环境下的体验
