# PC端设计规范

> B端后台管理系统/Web应用设计规范

---

## 一、设计尺寸

### 标准画布尺寸

| 分辨率 | 尺寸 | 说明 |
|--------|------|------|
| 笔记本 | 1366 × 768 | 最小适配尺寸 |
| 桌面标准 | 1440 × 900 | 主流尺寸 |
| 大屏 | 1920 × 1080 | 推荐设计尺寸 |
| **设计推荐** | **1440 × 900** | 兼顾主流和大屏 |

### 内容区域宽度

| 类型 | 宽度 | 说明 |
|------|------|------|
| 固定宽度 | 1200px / 1440px | 居中显示，两侧留白 |
| 流式宽度 | 100% | 自适应，有最小/最大宽度限制 |
| 混合布局 | 侧边栏固定 + 内容区自适应 | 后台系统常用 |

**推荐**：最大宽度1440px，最小宽度1280px

## 二、间距规范

### 基础间距体系

| 名称 | 数值 | 使用场景 |
|------|------|----------|
| 超小间距 | 4px | 图标与文字间距 |
| 小间距 | 8px | 紧密元素间 |
| 中间距 | 12px | 表单元素间 |
| 大间距 | 16px | 模块内元素 |
| 超大间距 | 24px | 模块间 |
| 特大间距 | 32px | 大模块分隔 |
| 页面间距 | 40px | 页面级分隔 |

### 页面边距

| 场景 | 边距 | 说明 |
|------|------|------|
| 页面内容区 | 24px | 内容与边缘距离 |
| 卡片内边距 | 16-24px | 卡片内部 |
| 表单边距 | 24px | 表单与容器边缘 |
| 表格边距 | 16px | 表格单元格内边距 |

### 组件间距

```
┌─────────────────────────────────────────────────────┐
```

## 三、色彩规范

### 主色体系

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 主色 | #1890FF | 主按钮、链接、选中状态 |
| 主色浅 | #40A9FF | 悬停状态 |
| 主色深 | #096DD9 | 按下状态 |
| 主色背景 | #E6F7FF | 选中背景、轻提示 |

### 中性色

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 标题文字 | #262626 | 页面标题、重要文字 |
| 正文文字 | #595959 | 正文内容 |
| 次要文字 | #8C8C8C | 辅助说明 |
| 占位文字 | #BFBFBF | 输入框提示 |
| 禁用文字 | #00000040 | 禁用状态 |
| 边框色 | #D9D9D9 | 边框、分割线 |
| 分割线 | #E8E8E8 | 内部分隔 |
| 背景浅 | #F5F5F5 | 页面背景、斑马纹 |
| 背景白 | #FFFFFF | 卡片背景 |
| 背景灰 | #FAFAFA | 表头、侧边栏 |

### 功能色

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 成功 | #52C41A | 成功提示、通过状态 |
| 警告 | #FAAD14 | 警告提示、待处理 |
| 错误 | #F5222D | 错误提示、删除、失败 |
| 信息 | #1890FF | 信息提示、进行中 |

### 色彩使用比例

```
70% - 中性色（背景、文字、边框）
20% - 主色（按钮、链接、选中）
10% - 功能色（状态提示）
```

## 五、布局系统

### 常见布局模式

#### 1. 侧边导航布局（最常用）

```
┌─────────────────────────────────────────────────────┐
│  Logo          顶部导航                    [用户] [通知] │ ← 顶部栏（64px）
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  导航菜单  │              内容区域                    │
│          │                                          │
│  · 首页   │  ┌──────────────────────────────────┐   │
│  · 数据   │  │         页面标题                   │   │
│  · 用户   │  ├──────────────────────────────────┤   │
│  · 订单   │  │                                  │   │
│  · 设置   │  │         内容区                     │   │
│          │  │                                  │   │
│          │  └──────────────────────────────────┘   │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
  200px                    自适应
```

**尺寸**：
- 顶部栏：64px
- 侧边栏：200-256px
- 内容区：自适应，最小宽度800px

#### 2. 顶部导航布局

```
┌─────────────────────────────────────────────────────┐
│  Logo    导航A  导航B  导航C          [用户] [设置]   │ ← 导航栏（64px）
├─────────────────────────────────────────────────────┤
│                                                     │
│                    内容区域                          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

#### 3. 混合布局

```
┌─────────────────────────────────────────────────────┐
│  Logo          顶部导航                    [用户]     │
├──────────┬──────────────────────────────────────────┤
│  主导航   │  二级导航                                 │
│          │  Tab1 | Tab2 | Tab3                      │
├──────────┼──────────────────────────────────────────┤
│          │                                          │
│  功能菜单  │              内容区域                    │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

### 栅格系统

| 属性 | 规范 |
|------|------|
| 列数 | 24列 |
| 列宽 | 自适应 |
| 列间距（Gutter） | 16px / 24px |
| 边距（Margin） | 24px |

## 六、组件规范

### 按钮 Button

#### 主按钮

| 状态 | 样式 |
|------|------|
| 默认 | 填充主色，白色文字，圆角4px |
| 悬停 | 主色浅 #40A9FF |
| 按下 | 主色深 #096DD9 |
| 禁用 | 灰色背景 #F5F5F5，灰色文字 #BFBFBF |

**尺寸**：
- 大按钮：高度40px，字号16px
- 中按钮：高度32px，字号14px
- 小按钮：高度24px，字号12px

#### 次按钮

- 白色背景，主色边框，主色文字
- 其他状态同主按钮

#### 文字按钮

- 纯文字，主色
- 悬停：文字颜色加深

### 输入框 Input

| 状态 | 样式 |
|------|------|
| 默认 | 白色背景，灰色边框 #D9D9D9 |
| 聚焦 | 主色边框，主色阴影 |
| 错误 | 红色边框，红色提示 |
| 禁用 | 灰色背景 #F5F5F5 |

**尺寸**：
- 高度：32px（小）/ 40px（中，默认）
- 内边距：8px 12px
- 圆角：4px

### 表单 Form

#### 表单布局

| 布局方式 | 适用场景 | 示例 |
|----------|----------|------|
| 水平布局 | 简单表单，标签短 | 标签 + 输入框同行 |
| 垂直布局 | 复杂表单，标签长 | 标签在上，输入框在下 |
| 行内布局 | 筛选条件 | 多个筛选条件一行 |

#### 表单元素间距

- 表单项间距：16-24px
- 标签与输入框间距：8px
- 错误提示间距：4px

### 表格 Table

#### 表格结构

```
┌─────────────────────────────────────────────────────┐
│  筛选栏 [输入框] [选择器] [日期] [搜索] [重置]        │
├─────────────────────────────────────────────────────┤
│  [批量操作]                              [分页信息]  │
├────────────────┬──────────┬──────────┬─────────────┤
│  [ ] 表头A      │  表头B   │  表头C   │    操作     │
├────────────────┼──────────┼──────────┼─────────────┤
│  [ ] 数据1      │  内容    │  内容    │ [编辑][删除] │
├────────────────┼──────────┼──────────┼─────────────┤
│  [ ] 数据2      │  内容    │  内容    │ [编辑][删除] │
├────────────────┴──────────┴──────────┴─────────────┤
│  [批量操作]                    共100条  < 1 2 3 ... > │
└─────────────────────────────────────────────────────┘
```

## 七、交互规范

## 九、响应式规则

### 断点设置

| 断点 | 宽度 | 布局调整 |
|------|------|----------|
| xs | < 576px | 移动端布局 |
| sm | ≥ 576px | 小屏适配 |
| md | ≥ 768px | 平板适配 |
| lg | ≥ 992px | 小桌面 |
| xl | ≥ 1200px | 标准桌面 |
| xxl | ≥ 1600px | 大屏 |

### 布局调整

| 元素 | 小屏(<768px) | 大屏(≥768px) |
|------|--------------|--------------|
| 侧边栏 | 收起为图标或隐藏 | 完全展开 |
| 表格 | 横向滚动 | 自适应 |
| 表单项 | 垂直排列 | 水平排列 |
| 操作按钮 | 图标按钮 | 文字按钮 |

## 十、设计检查清单

### 布局检查

- [ ] 内容区最大宽度1440px
- [ ] 最小宽度1280px，无横向滚动
- [ ] 侧边栏宽度200-256px
- [ ] 模块间距24px，元素间距16px

### 组件检查

- [ ] 按钮有悬停、按下状态
- [ ] 输入框有聚焦、错误状态
- [ ] 表格有斑马纹、悬停效果
- [ ] 弹窗有遮罩，可关闭

### 交互检查

- [ ] 支持键盘操作
- [ ] 有加载状态提示
- [ ] 空状态有引导
- [ ] 错误操作可撤销

### 响应式检查

- [ ] 小屏侧边栏可收起
- [ ] 表格可横向滚动
- [ ] 表单自适应布局
- [ ] 文字大小可读
