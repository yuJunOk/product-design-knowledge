# 移动端设计规范

> 移动端App/H5设计规范速查

---

## 一、设计尺寸

### 标准画布尺寸

| 设备 | 尺寸 | 说明 |
|------|------|------|
| iPhone SE | 375 × 667px | 小屏基准 |
| iPhone 12/13/14 | 390 × 844px | 标准屏 |
| iPhone 14 Pro Max | 430 × 932px | 大屏 |
| Android通用 | 360 × 640px / 360 × 760px | 主流尺寸 |
| **设计推荐** | **375 × 812px** | iPhone X标准，适配性好 |

### 系统区域高度

| 区域 | iPhone | Android | 说明 |
|------|--------|---------|------|
| 状态栏 | 44px | 24-32px | 系统预留，不放置内容 |
| 导航栏 | 44px | 48-56px | 页面标题和操作 |
| 底部安全区 | 34px | 0-16px | iPhone X以上机型 |
| 底部Tab栏 | 49px | 56px | 主导航入口 |
| **内容区高度** | **734px** | **可变** | 设计主要区域 |

## 二、间距规范

### 基础间距

| 名称 | 数值 | 使用场景 |
|------|------|----------|
| 超小间距 | 4px | 图标与文字间距 |
| 小间距 | 8px | 紧密元素间 |
| 中间距 | 12px | 模块内元素 |
| 大间距 | 16px | 模块间/页面边距 |
| 超大间距 | 24px | 大模块分隔 |
| 特大间距 | 32px | 页面级分隔 |

### 页面边距

| 场景 | 边距 | 说明 |
|------|------|------|
| 常规页面 | 16px | 左右边距 |
| 卡片列表 | 12-16px | 卡片与屏幕边缘 |
| 全屏图片 | 0px | 沉浸式内容 |
| 表单页面 | 16-24px | 根据内容调整 |

### 组件间距

```
┌─────────────────────────────────┐ ← 页面顶部（16px）
│                                 │
│  ┌─────────────────────────┐   │
│  │       模块A              │   │ ← 模块内边距（12-16px）
│  │  ┌─────┐ ┌─────┐        │   │
│  │  │元素1│ │元素2│ ←8px→  │   │ ← 元素间距（8-12px）
│  │  └─────┘ └─────┘        │   │
│  └─────────────────────────┘   │
│           ↓ 12px                │
│  ┌─────────────────────────┐   │
│  │       模块B              │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘ ← 页面底部（考虑安全区）
```

## 三、色彩规范

### 主色体系

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 主色 | #2563EB | 主按钮、重点强调、链接 |
| 主色浅 | #3B82F6 | 悬停状态 |
| 主色深 | #1D4ED8 | 按下状态 |
| 主色背景 | #DBEAFE | 标签背景、轻提示 |

### 中性色

| 用途 | 色值 | 使用场景 |
|------|------|----------|

| 正文文字 | #374151 | 正文内容 |
| 次要文字 | #6B7280 | 辅助说明、时间 |
| 占位文字 | #9CA3AF | 输入框提示 |
| 禁用文字 | #D1D5DB | 禁用状态 |
| 分割线 | #E5E7EB | 分隔线、边框 |
| 背景浅 | #F3F4F6 | 页面背景 |
| 背景白 | #FFFFFF | 卡片背景 |

### 功能色

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 成功 | #10B981 | 成功提示、完成状态 |
| 警告 | #F59E0B | 警告提示、需注意 |
| 错误 | #EF4444 | 错误提示、删除操作 |
| 信息 | #3B82F6 | 信息提示 |

```
60% - 中性色（背景、文字）

```

## 五、组件规范

### 按钮 Button

#### 主按钮

| 状态 | 样式 |
|------|------|
| 默认 | 填充主色，白色文字，圆角8px |
| 按下 | 主色深，缩放0.98 |
| 禁用 | 灰色背景，白色文字 |

**尺寸**：
- 大按钮：宽度100%，高度48px，字号16px
- 中按钮：宽度自适应，高度40px，字号14px
- 小按钮：宽度自适应，高度32px，字号13px

#### 次按钮

| 状态 | 样式 |
|------|------|
| 默认 | 白色背景，主色边框，主色文字 |
| 按下 | 主色浅背景 |
| 禁用 | 灰色边框，灰色文字 |

#### 文字按钮

- 纯文字，主色
- 无背景，无边框
- 适合弱操作

### 输入框 Input

| 状态 | 样式 |
|------|------|
| 默认 | 白色背景，灰色边框 |
| 聚焦 | 主色边框 |
| 错误 | 红色边框，红色提示文字 |
| 禁用 | 灰色背景，灰色文字 |

**尺寸**：
- 高度：48px
- 内边距：12px 16px
- 圆角：8px

### 列表 List

#### 单行列表

```
┌─────────────────────────────────┐
│ [图标]  标题              [>]   │
└─────────────────────────────────┘
```

- 高度：48-56px
- 左边距：16px
- 右边距：16px
- 分割线：底部1px #E5E7EB

#### 双行列表

```
┌─────────────────────────────────┐
│ [图]  主标题              [操作] │
│       副描述                    │
└─────────────────────────────────┘
```

- 高度：64-72px
- 主标题：15px #1F2937
- 副描述：13px #6B7280

## 六、交互规范

### 页面转场

| 操作 | 动画 | 时长 |
|------|------|------|
| 进入下级页面 | 从右向左滑入 | 300ms |
| 返回上级页面 | 从左向右滑出 | 300ms |
| Tab切换 | 无动画或淡入淡出 | 200ms |
| 模态弹窗 | 从底部滑入 | 300ms |
| 关闭弹窗 | 向下滑出 | 200ms |

### 按钮反馈

| 状态 | 反馈 |
|------|------|
| 按下 | 背景变深或缩放0.95 |
| 禁用 | 灰色，无反馈 |
| 加载中 | 显示loading，禁用点击 |

### 加载状态

| 场景 | 组件 | 说明 |
|------|------|------|
| 页面加载 | 全屏loading | 居中显示 |
| 下拉刷新 | 顶部loading | 下拉触发 |
| 上拉加载 | 底部loading | 上拉触发 |
| 局部加载 | 骨架屏 | 内容区域占位 |
| 按钮加载 | 按钮内loading | 禁用按钮 |

### Toast提示

| 类型 | 时长 | 位置 |
|------|------|------|
| 成功提示 | 2s | 居中或底部 |
| 失败提示 | 3s | 居中或底部 |
| 加载提示 | 持续 | 居中 |

**样式**：
- 背景：rgba(0,0,0,0.7)
- 文字：白色，14px
- 圆角：8px
- 内边距：12px 24px

## 七、适配规则

### 屏幕适配

| 适配方式 | 说明 | 使用场景 |
|----------|------|----------|
| 固定宽度 | 内容宽度固定，居中显示 | 简单页面 |
| 流式布局 | 宽度百分比，自动伸缩 | 列表、网格 |
| 响应式断点 | 不同尺寸不同布局 | 复杂页面 |
| 等比缩放 | 按宽度比例缩放 | 游戏、图表 |

### 安全区适配

```css
/* iPhone X+ 安全区 */
padding-bottom: env(safe-area-inset-bottom);
```

### 横屏处理

- 默认不支持横屏
- 特殊页面（视频、游戏）单独处理
- 横屏时重新布局

## 八、平台差异

### iOS vs Android

| 项目 | iOS | Android |
|------|-----|---------|
| 导航栏高度 | 44px | 48-56px |
| 标题位置 | 居中 | 左对齐 |
| 返回按钮 | < | ← |
| 底部Tab | 49px | 56px |
| 字体 | San Francisco | Roboto |
| 阴影 | 较轻 | 较重 |
| 圆角 | 较小 | 较大 |

### 设计建议

- 优先按iOS设计（用户接受度高）
- 关键组件按平台规范调整
- 保持整体风格一致

## 十、设计检查清单

### 布局检查

- [ ] 页面边距统一（16px）
- [ ] 模块间距合理（12-16px）
- [ ] 元素间距一致（8-12px）
- [ ] 考虑底部安全区

### 视觉检查

- [ ] 色彩使用符合规范
- [ ] 字体层级清晰
- [ ] 圆角使用一致
- [ ] 阴影适度不夸张

### 交互检查

- [ ] 触控目标≥44px
- [ ] 有明确的按下反馈
- [ ] 加载状态有提示
- [ ] 错误状态有处理

### 适配检查

- [ ] 适配不同屏幕尺寸
- [ ] 考虑刘海屏/圆角屏
- [ ] 文字大小可调整
- [ ] 横竖屏处理合理
