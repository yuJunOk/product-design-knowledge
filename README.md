## 🎯 这是什么？

这是一个系统化的**产品设计学习知识库**，涵盖：

- 📖 **设计方法论** - 用户体验五层面、目标导向设计等核心理论
- 📱 **平台规范** - 移动端、PC端、小程序设计规范
- 🛠️ **项目实战** - 完整项目模板 + Gua64真实案例
- 🧩 **组件模式** - 导航、列表、表单、反馈、空状态等设计模式
- 📚 **资源参考** - 设计规范链接、推荐书籍、工具推荐
- ✅ **复盘总结** - 设计检查清单、常见错误总结

> 💡 **适合人群**：产品经理初学者、想系统学习原型设计的开发者、需要规范文档参考的设计师

## 🚀 快速开始

### 方式一：理论学习路线

```
第1周：设计方法论
  └─ 阅读 00-设计方法论/ (4个文档)

第2周：规范学习
  └─ 阅读 01-平台规范/ + 03-组件模式库/

第3周：实战练习
  └─ 使用 02-项目实战/项目模板/ 完成一个项目

持续：复盘总结
  └─ 更新 05-复盘总结/ 沉淀个人经验
```

### 方式二：边学边做路线（推荐）

```
第1周：快速入门
  ├─ 读：01-用户体验五层面模型（框架）
  └─ 做：临摹 Gua64 现有页面

第2-3周：方法论+实战
  ├─ 读：目标导向设计 + 交互设计四策略
  └─ 做：为项目写人物角色 + 优化原型

第4-6周：完整项目流程
  └─ 用项目模板走完整设计流程
```

## 📖 使用指南

### 新建项目时

1. **复制模板**
   ```bash
   cp -r "02-项目实战/项目模板/" "02-项目实战/你的项目名称/"
   ```

2. **按顺序填写**
   - 01-项目概述.md → 明确项目背景和目标
   - 02-用户分析.md → 定义用户画像和场景
   - 03-信息架构.md → 规划页面结构和导航
   - 04-页面流程.md → 设计用户操作流程
   - 05-原型设计.md → 绘制原型和设计规范
   - 06-设计复盘.md → 项目总结和经验沉淀

### 日常学习时

| 学习阶段 | 推荐阅读 | 预计时间 |
|---------|---------|---------|
| 建立理论基础 | `00-设计方法论/` | 1-2周 |
| 了解平台规范 | `01-平台规范/` | 1周 |
| 掌握设计模式 | `03-组件模式库/` | 1周 |
| 实战项目 | `02-项目实战/gua64-app/` | 2-3周 |
| 沉淀经验 | `05-复盘总结/` | 持续 |
