# Gua64 原型设计

> 六十四卦应用原型设计规范与交付

---

## 设计规范

### 设计尺寸

| 项目 | 规格 |
|------|------|
| **设计画布** | 375 × 812px（iPhone X 标准） |
| **状态栏高度** | 44px |
| **导航栏高度** | 44px |
| **底部安全区** | 34px |
| **底部TabBar** | 49px |
| **内容区宽度** | 375px |

### 间距规范

| 类型 | 数值 | 使用场景 |
|------|------|----------|
| 页面边距 | 16px | 左右边距 |
| 模块间距 | 16px | 模块之间 |
| 元素间距 | 8-12px | 元素之间 |
| 大间距 | 24px | 重要分隔 |

### 色彩规范（基于项目AGENT.md）

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 主色 | #2563EB | 主按钮、重点强调 |
| 主色深 | #1D4ED8 | 按钮按下态 |
| 主色浅 | #DBEAFE | 背景、标签 |
| 背景渐变 | from-blue-50 to-white | 页面背景 |
| 变卦强调 | #EA580C | 变卦提示 |
| 文字主色 | #1F2937 | 标题、正文 |
| 文字次要 | #6B7280 | 辅助文字 |
| 分割线 | #E5E7EB | 分隔线 |

### 字体规范

| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| 大标题 | 20px | 600 | 页面大标题 |
| 标题 | 17px | 600 | 导航栏标题 |
| 正文 | 15px | 400 | 正文内容 |
| 辅助 | 13px | 400 | 辅助说明 |
| 小字 | 12px | 400 | 时间、标签 |

### 圆角规范

| 元素 | 圆角 |
|------|------|
| 大按钮 | rounded-full（胶囊形） |
| 卡片 | rounded-xl（12px） |
| 输入框 | rounded-lg（8px） |

| 属性 | 说明 |

│    │                     │     │

## 组件说明

### 主按钮

- 背景：蓝色渐变（from-blue-600 to-blue-700）
- 文字：白色，16px
- 圆角：rounded-full（胶囊形）
- 高度：48px
- 宽度：100% - 32px（左右边距16px）
- 阴影：hover:shadow-xl
- 点击反馈：active:scale-95

### 次按钮

- 背景：白色
- 边框：1px solid blue-600
- 文字：blue-600，16px
- 圆角：rounded-full
- 高度：48px

### 卡片

- 背景：白色
- 圆角：rounded-xl（12px）
- 阴影：shadow-sm
- 内边距：16px

### TabBar

- 背景：白色
- 高度：49px + 安全区34px
- 图标：24px
- 文字：10px
- 选中：蓝色
- 未选中：灰色
