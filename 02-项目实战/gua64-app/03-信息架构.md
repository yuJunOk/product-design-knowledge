# Gua64 信息架构

> 六十四卦应用信息架构设计

---

## 内容清单

### 内容类型

| 内容类型 | 说明 | 数量 | 来源 | 更新频率 |
|----------|------|------|------|----------|
| 卦象数据 | 64卦 × 每卦6爻 | 384条 | 系统内置 | 不更新 |
| 卦辞数据 | 卦辞、爻辞、象曰 | 64条 | 系统内置 | 不更新 |
| 历史记录 | 用户起卦记录 | 无限制 | 用户生成 | 实时 |
| 用户数据 | 设置、偏好 | 少量 | 用户生成 | 偶尔 |

### 内容属性

| 内容类型 | 关键属性 | 展示方式 |
|----------|----------|----------|
| 历史记录 | 时间、卦名、本卦、变卦 | 列表 |
| 卦象详情 | 卦图、卦辞、爻辞、解读 | 详情页 |

## 信息架构图

### 整体架构

```
                    ┌─────────────┐
                    │     首页     │
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
    │   自动起卦   │ │   手动录入   │ │   历史记录   │
    └──────┬──────┘ └──────┬──────┘ └──────┬──────┘
           │               │               │
           ▼               ▼               ▼
    ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
    │   卦象结果   │ │   卦象结果   │ │   历史详情   │
    └─────────────┘ └─────────────┘ └─────────────┘
```

### 页面清单

| 页面名称 | 页面类型 | 上级页面 | 下级页面 | 入口位置 | 权限要求 |
|----------|----------|----------|----------|----------|----------|
| 首页 | 聚合页 | - | 自动起卦、手动录入、历史 | 启动页 | 无 |
| 自动起卦 | 功能页 | 首页 | 卦象结果 | 首页入口 | 无 |
| 手动录入 | 功能页 | 首页 | 卦象结果 | 首页入口 | 无 |
| 卦象结果 | 详情页 | 自动/手动 | - | 起卦完成 | 无 |
| 历史记录 | 列表页 | 首页 | 历史详情 | TabBar | 无 |
| 历史详情 | 详情页 | 历史记录 | - | 点击历史项 | 无 |

## 导航设计

### 主导航（底部TabBar）

| 导航项 | 图标 | 对应页面 | 显示条件 | 排序 |
|--------|------|----------|----------|------|
| 首页 | 🏠 | 首页 | 始终显示 | 1 |
| 算卦 | ➕ | 自动起卦 | 始终显示 | 2 |

### 辅助导航

| 导航类型 | 位置 | 包含内容 |
|----------|------|----------|
| 返回按钮 | 页面左上角 | 返回上级页面 |

| 场景 | 导航行为 |

## 页面关系图

### 核心流程页面关系

```
[首页]
    │
    ├─→ [自动起卦] ──→ [卦象结果]
    │
    ├─→ [手动录入] ──→ [卦象结果]
    │
    └─→ [历史记录] ──→ [历史详情]
```

### 页面跳转规则

| 从页面 | 操作 | 到页面 | 跳转方式 |
|--------|------|--------|----------|
| 首页 | 点击自动起卦 | 自动起卦页 | 新页面 |
| 首页 | 点击手动录入 | 手动录入页 | 新页面 |
| 自动起卦 | 动画完成 | 卦象结果页 | 自动跳转 |
| 手动录入 | 确认提交 | 卦象结果页 | 跳转 |
| 卦象结果 | 点击保存 | 历史记录页 | 跳转 |
| 历史记录 | 点击历史项 | 历史详情页 | 新页面 |

---

## 设计原则

1. **扁平化原则**：核心功能2步内可达
2. **一致性原则**：起卦结果页统一展示
3. **可扩展原则**：预留互卦、错卦等扩展空间
