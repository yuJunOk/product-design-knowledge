# Gua64 页面流程

> 六十四卦应用用户操作流程

---

## 核心用户流程

### 流程1：自动起卦流程

#### 流程概述

| 要素 | 说明 |
|------|------|
| **流程名称** | 自动起卦 |
| **触发条件** | 用户点击首页"自动起卦"入口 |
| **用户目标** | 快速得到卦象解读 |
| **成功标准** | 完成起卦动画，展示卦象结果 |
| **预计耗时** | 30秒（含动画） |

#### 流程图

```
┌─────────┐
│  首页   │
└────┬────┘
     │ 点击"自动起卦"
     ▼
┌─────────┐
│ 自动起卦 │
│  页面   │
└────┬────┘
     │ 点击"开始起卦"
     ▼
┌─────────┐
│ 硬币动画 │◄──────┐
│ 第1爻   │       │
└────┬────┘       │
     │ 动画完成    │
     ▼             │
┌─────────┐       │
│ 硬币动画 │───────┘ 重复6次
│ 第2-6爻 │
└────┬────┘
     │ 全部完成
     ▼
┌─────────┐
│ 卦象结果 │
│  页面   │
└────┬────┘
     │ 点击"保存"
     ▼
┌─────────┐
│ 历史记录 │
└─────────┘
```

#### 页面详细说明

**页面1：自动起卦页**

| 元素 | 说明 |
|------|------|
| 标题 | "自动起卦" |
| 说明文字 | "点击下方按钮，模拟三枚硬币抛掷" |
| 主按钮 | "开始起卦" |
| 辅助按钮 | "查看说明"（可选） |

**页面2：硬币动画页**

| 元素 | 说明 |
|------|------|
| 动画区域 | 三枚硬币抛掷动画 |
| 进度提示 | "正在起卦：第X爻" |
| 已出结果 | 下方显示已确定的爻（阴/阳） |

**页面3：卦象结果页**

| 元素 | 说明 |
|------|------|
| 卦名 | "乾为天"（本卦名） |
| 卦图 | 六爻卦象图 |
| 变卦 | 如有动爻，显示变卦 |
| 卦辞 | 卦辞原文 |
| 爻辞 | 动爻爻辞（如有） |
| 操作按钮 | "保存"、"重新起卦"、"分享" |

### 流程2：手动录入流程

#### 流程概述

| 要素 | 说明 |
|------|------|
| **流程名称** | 手动录入 |
| **触发条件** | 用户已线下抛硬币，想记录结果 |
| **用户目标** | 准确录入六爻，查看解读 |
| **成功标准** | 完成六爻录入，生成卦象 |
| **预计耗时** | 1-2分钟 |

#### 流程图

```
┌─────────┐
│  首页   │
└────┬────┘
     │ 点击"手动录入"
     ▼
┌─────────┐
│ 手动录入 │
│  页面   │
└────┬────┘
     │ 逐爻选择阴阳
     ▼
┌─────────┐
│ 第1爻   │
│ [阴][阳]│
└────┬────┘
     │
     ▼
┌─────────┐
│ 第2-6爻 │
│ 同上    │
└────┬────┘
     │ 全部录入完成
     ▼
┌─────────┐
│ 确认页  │
│ 预览卦象 │
└────┬────┘
     │ 点击"生成卦象"
     ▼
┌─────────┐
│ 卦象结果 │
│ （同上） │
└─────────┘
```

#### 页面详细说明

**页面1：手动录入页**

| 元素 | 说明 |
|------|------|
| 标题 | "手动录入" |
| 说明 | "请按从下到上的顺序，选择每爻的阴阳" |
| 爻位提示 | "初爻"、"二爻"..."上爻" |
| 选择按钮 | "阴爻"（--）、"阳爻"（—） |
| 已选预览 | 下方实时显示已选的爻 |

### 流程3：查看历史流程

#### 流程概述

| 要素 | 说明 |
|------|------|
| **流程名称** | 查看历史 |
| **触发条件** | 用户想回顾之前的起卦记录 |
| **用户目标** | 找到历史记录，查看详情 |
| **成功标准** | 进入历史详情页 |

#### 流程图

```
┌─────────┐
│ 任意页面 │
└────┬────┘
     │ 点击底部Tab"历史"
     ▼
┌─────────┐
│ 历史记录 │
│  列表   │
└────┬────┘
     │ 点击某条历史
     ▼
┌─────────┐
│ 历史详情 │
│  页面   │
└─────────┘
```

## 页面详细说明

### 页面1：首页

#### 页面信息

| 属性 | 说明 |
|------|------|
| **页面名称** | 首页 |
| **页面类型** | 聚合页 |
| **入口来源** | 启动页 |
| **出口去向** | 自动起卦、手动录入、历史记录 |

#### 页面布局

```
┌─────────────────────────────────┐
│  状态栏                          │

│  Gua64 · 六十四                  │
├─────────────────────────────────┤
│                                 │
│         [Logo/插图]              │
│                                 │
│      通过三枚硬币，探索易学      │
│                                 │
│  ┌─────────────────────────┐   │
│  │      🎲 自动起卦        │   │
│  │    模拟硬币自动起卦     │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │      ✏️ 手动录入        │   │
│  │    记录线下起卦结果     │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│  🏠      ➕      📜              │
│ 首页    算卦    历史             │
└─────────────────────────────────┘
```

#### 模块说明

| 模块 | 内容 | 交互 |
|------|------|------|
| Logo区 | 应用Logo + 标语 | 点击无反应 |
| 自动起卦 | 大按钮，图标+文字 | 点击进入自动起卦页 |
| 手动录入 | 大按钮，图标+文字 | 点击进入手动录入页 |
| TabBar | 首页/算卦/历史 | 切换页面 |

## 全局交互规则

### 页面切换动画

| 操作 | 动画效果 |
|------|----------|
| 进入子页面 | 从右向左滑入 |
| 返回上级 | 从左向右滑出 |
| Tab切换 | 无动画 |

### 状态反馈

| 场景 | 反馈方式 |
|------|----------|
| 起卦完成 | 自动跳转结果页 |
| 保存成功 | Toast提示"已保存" |
| 加载中 | 硬币动画 |
