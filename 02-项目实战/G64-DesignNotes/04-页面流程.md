# Gua64 页面流程

> 六十四卦应用用户操作流程

---

## 核心用户流程

### 流程1：自动起卦流程

#### 流程概述

| 要素 | 说明 |
|------|------|
| **流程名称** | 自动起卦 |
| **触发条件** | 用户点击首页"自动起卦"入口 |
| **用户目标** | 快速得到卦象解读 |
| **成功标准** | 完成起卦动画，展示卦象结果 |
| **预计耗时** | 30秒（含动画） |

#### 流程图

```
┌─────────┐
│  首页   │
└────┬────┘
     │ 点击"自动起卦"
     ▼
┌─────────┐
│ 占事录入 │
│（可选）  │
└────┬────┘
     │ 输入所占之事
     ▼
┌─────────┐
│ 自动起卦 │
│  页面   │
└────┬────┘
     │ 点击"开始起卦"
     ▼
┌─────────┐
│ 硬币动画 │◄──────┐
│ 第1爻   │       │
└────┬────┘       │
     │ 动画完成    │
     ▼             │
┌─────────┐       │
│ 硬币动画 │───────┘ 重复6次
│ 第2-6爻 │
└────┬────┘
     │ 全部完成
     ▼
┌─────────┐
│ 卦象结果 │
│  页面   │
└────┬────┘
     │ 点击"保存"
     ▼
┌─────────┐
│ 历史记录 │
└─────────┘
```

#### 页面详细说明

**页面1：占事录入页（可选）**

| 元素 | 说明 |
|------|------|
| 标题 | "占事录入" |
| 说明文字 | "请输入您所占之事，方便日后回顾" |
| 输入框 | 多行文本输入 |
| 主按钮 | "开始起卦" |
| 辅助按钮 | "跳过，直接起卦" |

**页面2：自动起卦页**

| 元素 | 说明 |
|------|------|
| 标题 | "自动起卦" |
| 说明文字 | "点击下方按钮，模拟三枚硬币抛掷" |
| 主按钮 | "开始起卦" |
| 辅助按钮 | "查看说明"（可选） |

**页面3：硬币动画页**

| 元素 | 说明 |
|------|------|
| 动画区域 | 三枚硬币抛掷动画 |
| 进度提示 | "正在起卦：第X爻" |
| 已出结果 | 下方显示已确定的爻（阴/阳） |

**页面4：卦象结果页**

| 元素 | 说明 |
|------|------|
| 卦名 | "乾为天"（本卦名） |
| 卦图 | 六爻卦象图 |
| 变卦 | 如有动爻，显示变卦 |
| 卦辞 | 卦辞原文 |
| 爻辞 | 动爻爻辞（如有） |
| 操作按钮 | "保存"、"重新起卦"、"分享" |

### 流程2：手动录入流程

#### 流程概述

| 要素 | 说明 |
|------|------|
| **流程名称** | 手动录入 |
| **触发条件** | 用户已线下抛硬币，想记录结果 |
| **用户目标** | 准确录入六爻，查看解读 |
| **成功标准** | 完成六爻录入，生成卦象 |
| **预计耗时** | 1-2分钟 |

#### 流程图

```
┌─────────┐

└────┬────┘
     │ 点击"手动录入"
     ▼

│（可选）  │
└────┬────┘
     │
     ▼
┌─────────┐
│ 手动录入 │
│  页面   │
└────┬────┘
     │ 逐爻选择阴阳
     ▼
┌─────────┐
│ 第1爻   │
│ [阴][阳]│
└────┬────┘
     │
     ▼
┌─────────┐
│ 第2-6爻 │
│ 同上    │
└────┬────┘
     │ 全部录入完成
     ▼
┌─────────┐
│ 确认页  │
│ 预览卦象 │
└────┬────┘
     │ 点击"生成卦象"
     ▼
┌─────────┐
│ 卦象结果 │
│ （同上） │
└─────────┘
```

#### 页面详细说明

**页面1：手动录入页**

| 元素 | 说明 |
|------|------|
| 标题 | "手动录入" |
| 说明 | "请按从下到上的顺序，选择每爻的阴阳" |
| 爻位提示 | "初爻"、"二爻"..."上爻" |
| 选择按钮 | "阴爻"（--）、"阳爻"（—） |

### 流程3：查看历史流程

#### 流程概述

| 要素 | 说明 |
|------|------|
| **流程名称** | 查看历史 |
| **触发条件** | 用户想回顾之前的起卦记录 |
| **用户目标** | 找到历史记录，查看详情 |
| **成功标准** | 进入历史详情页 |

#### 流程图

```
┌─────────┐
│ 任意页面 │
└────┬────┘
     │ 点击底部Tab"历史"
     ▼
┌─────────┐
│ 历史记录 │
│  列表   │
└────┬────┘
     │ 点击某条历史
     ▼
┌─────────┐
│ 历史详情 │
│  页面   │
└────┬────┘
     ├─→ 编辑标题/笔记
     ├─→ 分享卦局
     └─→ 删除卦局
```

## 异常流程

### 流程异常1：网络异常（分享时）

```
用户点击分享
    │
    ▼
检测网络状态
    │
    ├─→ 网络正常 ─→ 正常分享流程
    │
    └─→ 网络异常
         │
         ▼
    ┌─────────┐
    │ 提示用户 │
    │ "网络异常， │
    │  请检查网络后重试"
    └────┬────┘
         │
         ▼
    [重试] [取消]
```

### 流程异常2：存储空间不足

```
用户保存卦局
    │
    ▼
检测存储空间
    │
    ├─→ 空间充足 ─→ 正常保存
    │
    └─→ 空间不足
         │
         ▼
    ┌─────────┐
    │ 提示用户 │
    │ "存储空间不足，│
    │  请清理历史记录"
    └────┬────┘
         │
         ▼
    [去清理] [取消]
```
