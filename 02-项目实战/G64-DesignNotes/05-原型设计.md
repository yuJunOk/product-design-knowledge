# Gua64 原型设计

> 六十四卦应用原型设计规范与交付

---

## 设计规范

### 设计尺寸

| 项目 | 规格 |
|------|------|
| **设计画布** | 375 × 812px（iPhone X 标准） |
| **状态栏高度** | 44px |
| **导航栏高度** | 44px |
| **底部安全区** | 34px |
| **底部TabBar** | 49px |
| **内容区宽度** | 375px |

### 间距规范

| 类型 | 数值 | 使用场景 |
|------|------|----------|
| 页面边距 | 16px | 左右边距 |
| 模块间距 | 16px | 模块之间 |
| 元素间距 | 8-12px | 元素之间 |
| 大间距 | 24px | 重要分隔 |

### 色彩规范（基于项目AGENT.md）

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 主色 | #2563EB | 主按钮、重点强调 |
| 主色深 | #1D4ED8 | 按钮按下态 |
| 主色浅 | #DBEAFE | 背景、标签 |
| 背景渐变 | from-blue-50 to-white | 页面背景 |
| 变卦强调 | #EA580C | 变卦提示 |
| 文字主色 | #1F2937 | 标题、正文 |
| 文字次要 | #6B7280 | 辅助文字 |
| 分割线 | #E5E7EB | 分隔线 |
| 吉 | #10B981 | 吉评级 |
| 凶 | #EF4444 | 凶评级 |
| 平 | #6B7280 | 平评级 |

### 字体规范

| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| 大标题 | 20px | 600 | 页面大标题 |
| 标题 | 17px | 600 | 导航栏标题 |
| 正文 | 15px | 400 | 正文内容 |
| 辅助 | 13px | 400 | 辅助说明 |
| 小字 | 12px | 400 | 时间、标签 |

### 圆角规范

| 元素 | 圆角 |
|------|------|
| 大按钮 | rounded-full（胶囊形） |
| 卡片 | rounded-xl（12px） |
| 输入框 | rounded-lg（8px） |
| 小标签 | rounded-md（6px） |

#### 文献数据说明

| 文献类型 | 说明 | 展示方式 |
|----------|------|----------|
| 卦辞 | 每卦的卦辞原文 | 全文展示 |
| 爻辞 | 动爻的爻辞原文 | 高亮展示 |
| 彖辞 | 彖传对该卦的解释 | 全文展示 |
| 象曰 | 象传对该卦的解释 | 全文展示 |
| 河洛理数 | 卦的河洛理数解读 | 全文展示 |
| 吉凶平 | 卦及动爻的吉凶评级 | 标签展示 |

**关于河洛理数**：
- 每卦有对应的河洛理数解读
- 爻本身也有河洛理数的数理属性
- 在卦象结果页中，卦的河洛理数与卦辞等一同展示
- 如需展示爻的河洛理数，可在动爻详情中补充
