## 内容清单

### 内容类型

| 内容类型 | 说明 | 数量 | 来源 | 更新频率 |
|----------|------|------|------|----------|
| 卦象数据 | 64卦 × 每卦6爻 | 384条 | 系统内置 | 不更新 |
| 卦辞数据 | 卦辞、爻辞、象曰、彖辞 | 64条 | 系统内置 | 不更新 |
| 河洛理数（卦） | 每卦的河洛理数解读 | 64条 | 系统内置 | 不更新 |
| 河洛理数（爻） | 每爻的河洛理数数理 | 384条 | 系统内置 | 不更新 |
| 吉凶平数据 | 每卦及每爻的吉凶评级 | 384条 | 系统内置 | 不更新 |
| 历史记录 | 用户起卦记录 | 无限制 | 用户生成 | 实时 |
| 收藏数据 | 用户收藏的卦局 | 无限制 | 用户生成 | 实时 |
| 笔记数据 | 用户对卦局的笔记 | 无限制 | 用户生成 | 偶尔 |
| 用户数据 | 设置、偏好、统计数据 | 少量 | 用户生成 | 偶尔 |

### 内容属性

| 内容类型 | 关键属性 | 展示方式 |
|----------|----------|----------|
| 历史记录 | 时间、卦名、本卦、变卦、所占之事、自定义标题、笔记 | 列表/卡片 |
| 收藏卦局 | 卦名、收藏时间、分类标签、备注 | 列表/网格 |
| 卦象详情 | 卦图、卦辞、爻辞、象曰、彖辞、河洛理数（卦）、河洛理数（爻）、吉凶平、译文 | 详情页 |
| 六十四卦库 | 卦名、卦图、八卦分类、吉凶属性 | 列表/网格 |

## 数据流转

### 起卦数据流

```
用户操作 ──→ 生成六爻 ──→ 计算本卦/变卦 ──→ 查询文献数据 ──→ 展示结果
                │              │                  │
                └─→ 保存到SQLite ────────────────┘
```

### 历史数据流

```
历史记录 ──→ SQLite查询 ──→ 列表展示 ──→ 用户操作（编辑/删除/分享）
                                              │
                                              └─→ 更新SQLite
```

### 数据导入导出流

```
导出：SQLite ──→ JSON序列化 ──→ 文件保存 ──→ 分享/存储
导入：文件选择 ──→ JSON解析 ──→ 数据验证 ──→ SQLite写入
```

## 设计原则

1. **扁平化原则**：核心功能2步内可达，起卦流程3步完成
2. **一致性原则**：起卦结果页统一展示，历史详情与卦象结果保持一致的展示结构
3. **可扩展原则**：预留互卦、错卦等扩展空间，支持未来AI解卦功能
4. **离线优先**：所有功能无需网络，数据本地存储
5. **双模式支持**：自动起卦和手动录入并行，满足不同用户需求
6. **高效管理**：支持搜索、筛选、分类，方便管理大量历史记录
7. **数据安全**：本地存储，支持导入导出备份
