### 基础组件

#### 按钮 Button

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 填充主色，白色文字 | 主要操作 |
| 次按钮 | 白色背景，主色边框 | 次要操作 |
| 文字按钮 | 纯文字，主色 | 弱操作 |
| 禁用按钮 | 灰色背景 | 不可点击 |

**尺寸**：
- 大按钮：宽度100%，高度48px
- 中按钮：宽度自适应，高度40px
- 小按钮：宽度自适应，高度32px

| 状态 | 样式 |
|------|------|
| 默认 | 灰色边框，白色背景 |

**尺寸**：
- 高度：48px
- 内边距：12px 16px

## 设计检查清单

### 功能性检查

- [ ] 所有页面有明确的标题
- [ ] 每个操作都有反馈
- [ ] 可以返回上级页面
- [ ] 空状态有处理
- [ ] 错误状态有提示
- [ ] 加载状态有指示

### 可用性检查

- [ ] 核心功能3步内可达
- [ ] 重要信息首屏可见
- [ ] 按钮大小适合点击（最小44×44px）
- [ ] 文字清晰可读（对比度足够）
- [ ] 输入框有适当的键盘类型

### 一致性检查

- [ ] 相同元素样式一致
- [ ] 相同操作反馈一致
- [ ] 间距规范统一
- [ ] 色彩使用规范
