# 设计检查清单

> 设计交付前的系统性检查，确保设计质量

---

## 一、战略层检查

### 产品目标

- [ ] 产品定位清晰明确
- [ ] 核心用户群体已定义
- [ ] 解决的核心痛点已明确
- [ ] 与竞品有差异化价值

### 用户需求

- [ ] 用户画像已完成
- [ ] 核心场景已梳理
- [ ] 用户需求已验证（非假设）
- [ ] 需求优先级已确定

---

## 二、范围层检查

### 功能范围

- [ ] 功能清单完整
- [ ] 核心功能（P0）已确定
- [ ] 功能边界清晰（做什么/不做什么）
- [ ] MVP范围合理

### 内容需求

- [ ] 内容类型已明确
- [ ] 内容来源已确定
- [ ] 内容更新机制已规划

---

## 三、结构层检查

### 信息架构

- [ ] 页面结构清晰
- [ ] 分类体系合理
- [ ] 层级深度适中（不超过3层）
- [ ] 导航路径明确

### 用户流程

- [ ] 核心流程完整
- [ ] 流程步骤精简
- [ ] 异常情况已考虑
- [ ] 流程有明确的起点和终点

---

## 四、框架层检查

### 界面布局

- [ ] 页面布局符合平台规范
- [ ] 重要信息首屏可见
- [ ] 视觉层级清晰
- [ ] 留白合理，不拥挤

### 导航设计

- [ ] 导航位置符合用户习惯
- [ ] 当前位置指示明确
- [ ] 返回路径清晰
- [ ] 快捷入口合理

### 交互设计

- [ ] 交互方式符合平台规范
- [ ] 操作反馈及时
- [ ] 手势操作符合习惯
- [ ] 交互动画适度

---

## 五、表现层检查

### 视觉设计

- [ ] 色彩使用符合规范
- [ ] 字体层级清晰
- [ ] 图标风格统一
- [ ] 图片质量达标

### 品牌传达

- [ ] 品牌元素正确使用
- [ ] 整体风格符合品牌调性
- [ ] 情感化设计到位

---

## 六、移动端专项检查

### 布局适配

- [ ] 适配不同屏幕尺寸
- [ ] 考虑刘海屏/圆角屏
- [ ] 底部安全区处理
- [ ] 横竖屏切换处理

### 交互适配

- [ ] 触摸目标足够大（最小44×44px）
- [ ] 支持手势操作
- [ ] 键盘弹出处理

### 性能考虑

- [ ] 图片已压缩
- [ ] 非必要动画已简化
- [ ] 长列表有优化方案

---

## 七、PC端专项检查

### 布局适配

- [ ] 多列布局处理

### 交互适配

## 八、表单专项检查

### 表单结构

## 使用说明

### 检查时机

1. **设计过程中**：随时自查
2. **设计评审前**：完整检查
3. **开发交付前**：最终检查

### 检查结果处理

| 优先级 | 处理方式 |
|--------|----------|
| 必须修复 | 不修复不能交付 |
| 建议修复 | 尽量修复，时间紧可记录后续处理 |
| 可选优化 | 记录为优化项，后续版本处理 |

### 检查记录

| 日期 | 检查人 | 版本 | 问题数 | 状态 |
|------|--------|------|--------|------|
| | | | | □ 通过 □ 需修改 |

## 快速检查版（5分钟版）

时间紧张时，优先检查以下10项：

1. [ ] 核心功能3步内可达
2. [ ] 重要信息首屏可见
3. [ ] 每个操作都有反馈
4. [ ] 可以返回上级页面
5. [ ] 空状态有处理
6. [ ] 错误状态有提示
7. [ ] 按钮大小适合点击
8. [ ] 文字清晰可读
9. [ ] 色彩使用规范
10. [ ] 交互符合平台习惯
